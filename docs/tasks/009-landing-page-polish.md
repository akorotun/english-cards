# Task 009 — Покращення головної сторінки

**Файл:** `docs/tasks/009-landing-page-polish.md`  
**Статус:** Етап 1 виконано\
**Проєкт:** English Cards — Laravel 13 / PHP 8.4 / MySQL / Docker Compose (WSL2)  
**Тип:** UI / responsive / theme preferences

## 1. Мета

Покращити головну сторінку English Cards:

1. Додати перемикач оформлення (системна / світла / темна тема), доступний ще до авторизації.
2. Покращити розташування кнопок реєстрації, входу та демодоступу в мобільній версії.

Не змінювати загальну концепцію та дизайн головної сторінки.

**Implementation notes:**

- Змінені файли: `resources/views/layouts/app.blade.php`, `resources/views/profiles/partials/theme-menu.blade.php`, `resources/views/welcome.blade.php`, `resources/js/app.js`, `resources/css/app.css`, `tests/Feature/PublicHomeTest.php`, `tests/Feature/AuthProfileJourneyTest.php`, бізнес-логіка та цей task.
- Рішення: спільне меню тем профілю доповнено гостьовими кнопками лише на головній. Гостьовий вибір зберігається в `localStorage` під ключем `english-cards-guest-theme`; усі гостьові сторінки читають лише допустиме значення до підключення стилів, а відсутнє/некоректне чи недоступне сховище дає системну тему. Обмеження сховища не блокують сторінку. Авторизований layout не читає гостьовий ключ і використовує тему профілю. На мобільних дії впорядковано вертикально, на desktop — наявний горизонтальний порядок.
- Перевірки: після перевірки тестової конфігурації та наявності `english_cards_test` команда `docker compose exec -T app php artisan test --compact tests/Feature/PublicHomeTest.php tests/Feature/AuthProfileJourneyTest.php tests/Feature/LearningProfileTest.php tests/Feature/LearningProfileManagementTest.php` — 22 тести, 331 assertion; `docker compose exec -T node node --test tests/JavaScript/*.test.js` — 27 пройшли; `docker compose exec -T app vendor/bin/pint --dirty --format agent` — passed; `docker compose exec -T node npm run build` — успішно; `git diff --check` — без помилок.
- Chromium/CDP: перевірено три теми, перезавантаження, повернення на сторінку, зміну системної теми, переходи до входу й демо, некоректне збережене значення. На 320/390/412/1280 px у світлій і темній темах перевірено порядок, ширину кнопок, розташування перемикача та відсутність горизонтального переповнення; оглянуто скриншоти. В ізольованій `english_cards_test` гостьове `dark` не замінило `light` тестового профілю після входу і на головній; тестовий акаунт прибрано, сервер та тимчасові браузери завершено.
- Обмеження: перевірено у headless Chromium; Firefox, Safari й фізичні пристрої не перевірялися. Миготіння запобігається раннім застосуванням теми до стилів, але не вимірювалося покадрово. Laravel міг створити технічний запис гостьової сесії у dev-БД під час читання сторінок; навчальні дані не змінювалися.
