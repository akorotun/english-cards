# Task 009 — Покращення головної сторінки

**Файл:** `docs/tasks/009-landing-page-polish.md`  
**Статус:** заплановано  
**Проєкт:** English Cards — Laravel 13 / PHP 8.4 / MySQL / Docker Compose (WSL2)  
**Тип:** UI / responsive / theme preferences

## 1. Мета

Покращити головну сторінку English Cards:

1. Додати перемикач оформлення (системна / світла / темна тема), доступний ще до авторизації.
2. Покращити розташування кнопок реєстрації, входу та демодоступу в мобільній версії.

Не змінювати загальну концепцію та дизайн головної сторінки.

## 2. Етап 1. Перемикач теми та мобільні кнопки

**Результат:** відвідувач може вибрати оформлення ще до реєстрації, а основні дії на мобільних пристроях мають зрозуміле та охайне розташування.

### 2.1. Перемикач теми

- [ ] Додати компактний перемикач теми у верхню панель головної сторінки, поруч із логотипом English Cards (вирівняти праворуч).
- [ ] Передбачити три варіанти: **Системна / Світла / Темна**. Використати наявний механізм перемикання тем, якщо він підходить.
- [ ] Для неавторизованих відвідувачів зберігати вибір у браузерному `localStorage` (не IndexedDB).
- [ ] Після повторного відкриття сторінки відновлювати попередній вибір. Якщо налаштування відсутнє — використовувати системну тему.
- [ ] Варіант «Системна» повинен враховувати поточні налаштування оформлення операційної системи.
- [ ] Для авторизованих користувачів джерелом налаштування залишається `learning_profiles.theme_preference`. Не замінювати збережену тему профілю гостьовим значенням із `localStorage`.
- [ ] Зберегти правильне застосування теми під час переходів між сторінками та уникнути помітного миготіння неправильної теми під час завантаження.
- [ ] Не створювати нових таблиць, полів або залежностей.

### 2.2. Розташування кнопок на мобільних пристроях

На мобільних ширинах змінити компонування блоку дій:

1. **Зареєструватися** — основна кнопка, на всю доступну ширину.
2. **Спробувати без реєстрації** — друга кнопка, також на всю доступну ширину.
3. **Увійти** — компактне текстове посилання під кнопками, наприклад: «Вже маєте акаунт? Увійти».

- [ ] Реалізувати вертикальне розташування без випадкового перенесення кнопок браузером.
- [ ] Зберегти наявні маршрути та функціональність усіх трьох дій.
- [ ] На desktop залишити поточне горизонтальне компонування кнопок.
- [ ] Зберегти відступи, візуальну ієрархію та адаптивність.

### 2.3. Перевірки

- [ ] Перевірити перемикання між усіма трьома темами на головній сторінці.
- [ ] Перевірити збереження вибору після перезавантаження сторінки та повторного відкриття.
- [ ] Перевірити роботу системної теми при зміні системного оформлення.
- [ ] Переконатися, що авторизований користувач продовжує використовувати налаштування свого навчального профілю.
- [ ] Перевірити мобільне компонування на ширинах 320, 390 та 412 px.
- [ ] Перевірити desktop-компонування.
- [ ] Перевірити світлу й темну теми.
- [ ] Перевірити відсутність горизонтального прокручування та візуальних дефектів.
- [ ] Запустити релевантні автоматизовані тести, Pint, збірку frontend та `git diff --check`.

**Implementation notes:**

Заповнити після виконання: змінені файли, реалізовані рішення, команди та результати перевірок, обмеження або блокери.

## 3. Обмеження

- Не змінювати структуру БД та модель навчальних профілів.
- Не використовувати IndexedDB для збереження гостьових налаштувань.
- Не змінювати логіку авторизації, реєстрації, деморежиму та навчання.
- Не переробляти інші сторінки застосунку.
- Не встановлювати нові Composer/npm-залежності.
- Не змінювати Docker-конфігурацію.
- Якщо реалізація потребує непогоджених архітектурних змін — зупинитися й запропонувати варіанти.

## 5. Критерії приймання

- Перемикач теми доступний до авторизації.
- Гостьове налаштування зберігається в `localStorage`.
- Авторизований користувач використовує налаштування свого профілю.
- На мобільних кнопки мають охайне вертикальне компонування.
- На desktop збережено поточне горизонтальне компонування.
- Світла, темна та системна теми працюють коректно.
- Усі доступні перевірки пройдені або неперевірені пункти чітко задокументовані.
